## §C — Proposed new file structure: `phase_graph/`

directory `phase_graph/` (Prism's own naming for "executable phase
graph"; the original tinygrad connection is absorbed). The public
re-export in `lib.rs` becomes `pub use phase_graph::{...}`.

## §F — Dependency order between new files

The submodules have a layered dependency:

1. **`uop.rs`** — no deps on siblings. Defines `UOp`, `UOpKind`,
   `UOpId`.
2. **`shape.rs`** — no deps on siblings. Standalone dtype / shape
   utilities.
3. **`plan.rs`** — no deps on siblings. Standalone execution-plan
   envelopes.
4. **`scalar.rs`** — depends on `uop` (needs `UOp`).
5. **`kernel_op.rs`** — depends on `uop` (needs `UOp`, `UOpId`).
6. **`graph.rs`** — depends on `uop` (needs `UOp`, `UOpKind`).
7. **`kernel_group.rs`** — depends on `graph` (needs `TinyGraph`),
   `uop`, `kernel_op`, `scalar`, `shape`.
8. **`render.rs`** — depends on `kernel_op` (renders the ops).
9. **`capture.rs`** — depends on `graph` (needs `TinyGraph`),
   `kernel_group`, `uop`, `plan`, `shape`.
10. **`mod.rs`** — declares all of the above; depends on all of them.

Order of creation (lowest deps first): `uop`, `shape`, `plan`, `scalar`,
`kernel_op`, `graph`, `kernel_group`, `render`, `capture`, `mod.rs`.

- **Error context** → `thiserror` `Error` derive on `GraphError` in
  `graph.rs`. The current file's other `Result<_, String>` returns
  stay as-is (per the rust-quality migration backlog, but not part of
  this decomposition).

  data types in `uop.rs` and `plan.rs`.

There is no `helpers.rs`, `common.rs`, `utils.rs`, `misc.rs`, or
`shared.rs` file introduced by this work.
