PRISM ARTIFACT / SEALED DEPLOYMENT CONTRACT

The runtime should not
rediscover the deployment.

A ComputeImage is the versioned boundary between compilation and execution. It keeps semantic identity, physical representation, target views, plans, payloads, and validation evidence attributable after compilation ends.

More than a renamed checkpoint.

Model formats describe weights and metadata. A deployment artifact must also preserve how those weights were admitted, laid out, routed, and validated for a target.

MODEL CHECKPOINT

Weights + metadata; runtime reconstructs policy.

COMPUTEIMAGE

Logical identity + layouts + execution views + plans + receipts + payloads.

One artifact.

The artifact format and assembly paths are implemented, but each target view remains subject to its own compiler, runtime, hardware, and evidence gates. Prism deliberately separates “artifact exists” from “this route is qualified.”
