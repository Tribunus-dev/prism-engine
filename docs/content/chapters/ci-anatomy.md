One artifact. Six inspectable strata.

- **Metadata** — identity, schema, source digest
- **Logical tensors** — meaning, shape, graph role
- **Physical layouts** — codec, tiles, alignment
- **Execution views** — lane, offsets, residency
- **Plan + receipts** — admission, route, evidence
- **Payloads** — mapped tensor and metadata bytes
