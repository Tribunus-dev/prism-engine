title: Authority
order: 1
---

State changes pass through a constitutional boundary. Canonical ECS
state owns accepted work, lifecycle, ownership, leases, committed
outcomes, and terminal failures. Queues, caches, backend handles,
and analytical projections remain derived or ephemeral.

1. **Command** — Intent enters through a validated operation.
2. **Transaction** — Preconditions, effects, and identities are checked.
3. **Event** — Durable state change is recorded before acknowledgement.
4. **Projection** — Views can be rebuilt from canonical history.
