Use the complete Apple build path.

- **Apple Silicon Mac** — The most complete public end-user path currently targets Apple Silicon.
- **Rust toolchain** — Use the repository toolchain and a release build.
- **Xcode command-line tools** — Required by the Apple compilation and Metal surfaces.
- **Pre-1.0 boundary** — APIs, artifacts, models, and backend contracts may change.
