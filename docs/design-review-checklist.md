# Prism Design Proof

Use this proof for every new scene, interaction, claim, animation, or navigation change. An interaction belongs in the shared experience only when its answers are explicit.

## Constitutional review

Can this interaction exist without violating computational intent and provenance?

Can it reveal information without dumping it or inventing certainty?

Can it maintain the identity of the persistent computational subject through every representation change?

Can it make the next narrative question clear?

Can the visitor state which misconception they are leaving behind and which mental model they are taking forward?

## Evidence review

Does every statement have an explicit knowledge source and existence state?

Are measured observation, compile verification, repository evidence, derivation, illustration, research direction, and speculation visually distinct?

Can the interaction exist without implying hardware execution where only planning or compilation has been verified?

Can the visitor inspect the source boundary when the claim requires it?

## Experience review

Does the scene implement intent, reveal, explore, commit, observe, and persist?

Does the visitor know where they came from and where they go next without relying only on labels?

Does the interaction answer one question while introducing one new question?

Does the same scene work at Discover, Understand, Inspect, and Reference density?

Does it represent unknown, partial, deferred, rejected, or experimental outcomes when they are the truthful result?

## Optical review

Does every light have a source?

Does every color change communicate state?

Does motion use the shared time vocabulary and preserve object continuity?

Are geometry, spacing, typography, and focus behavior consistent with the Physics of Prism?

## Technical review

Is the interaction keyboard reachable?

Does reduced-motion mode preserve the information hierarchy?

Does the scene degrade meaningfully without JavaScript?

Does the generated route build cleanly and avoid duplicate scene state?

Does the shared runtime load in a deterministic order, and does the route contract verifier cover every generated page?

Does persistent state remain explicit, scoped to the computational subject, and independent from hidden visitor profiling?

Can this interaction exist without evidence?

Can this interaction exist without object permanence?
