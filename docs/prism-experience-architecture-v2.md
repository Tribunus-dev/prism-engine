# Prism Experience Architecture v2

The Prism Observatory is the canonical interface language for the Prism ecosystem. It is an observation environment, not a collection of pages.

## Instruments

Identity observes intent. Structure observes semantic relationships. Transformation observes compiler search. Embodiment observes the ComputeImage. Execution observes realization. Evidence observes truth. Scale observes Fabric behavior.

## Observation grammar

Every instrument follows `intent → observation → transformation → commit → execution → evidence → reflection`. The website, debugger, and inspector are renderers of the same protocol.

## Knowledge layers

Layer Zero is intuition. Layer One is architecture. Layer Two is implementation. Layer Three is evidence. Layer Four is repository. A visitor changes depth without leaving the same instrument or changing the underlying claim.

## Causality

Scenes should explain `cause → effect → evidence → consequence`, not merely present a chronological timeline.

## Mental model engine

Every observation declares what the visitor believed before, what they should believe after, what changed, what remained invariant, what became observable, and what is still hidden.

## Object system

ComputeImage is a family of observations over one object: silhouette, cross-section, topology, ABI, execution, receipts, history, diff, Fabric, capabilities, and relationships.

## Research frontier

Open questions, evolutionary search, semantic compression, behavior preservation, distributed intent, compiler biology, Engrams, and hardware co-design remain explicitly marked as research directions rather than product promises.
